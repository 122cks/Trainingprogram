AI 에이전트 이해와
실습 환경 설정		 AI 에이전트도구를 사용해 여러 단계의 업무를 수행하는 AI 챗봇과 에이전트의 차이, 기본 용어를 이해하고 데스크톱 앱 설치·설정·작업 폴더 연결을 실습합니다. 50분 필수: 설치 가능한 노트북, 사용 계정 로그인, 네트워크 확인.
수업 안에서: 앱 설정·작업 폴더 연결·파일 읽기 시험.
AI 에이전트를 활용한
영수증 정리와 엑셀 보고서 자동화		 문서·데이터 자동화자료에서 정보를 추출하고 표·계산 결과로 정리 영수증 사진에서 날짜·품목·금액을 추출하고, 상세 내역과 항목별 합계가 담긴 엑셀 정산표를 만듭니다. 30분 선행: 공통 환경 설정.
필수: 예제 영수증, 엑셀 열람 환경, 파일 생성 시험.
파일 정리 에이전트
기초 실습		 작업 위임AI에게 분석·계획·실행을 단계적으로 요청 공문·업무 파일을 분석하고 분류 계획을 확인한 뒤, 원본을 보존하면서 복사본을 정리합니다. 20분 선행: 공통 환경 설정.
필수: 압축 해제한 예제 폴더와 복사 결과 저장 위치.
브라우저 연동 에이전트로
체험학습 장소 비교하기		 Chrome 연동평소 사용하는 브라우저의 열린 자료를 AI와 연결 네이버지도 저장 목록에서 후보 장소를 읽고 위치·운영시간·요금 등을 비교표로 정리합니다. 20분 선행: 공통 환경 설정.
필수: Chrome 설치·확장/연결 설정, 예제 지도 계정과 저장 목록. 열린 탭 읽기 확인.
웹 리서치 에이전트와
Sites로 조사 결과 공유하기		 웹 리서치 & Sites공식 자료 조사와 출처·기준일 확인 및 웹페이지 제작 공공자료를 조사하고, 출처가 있는 비교표·그래프·설명을 한 장짜리 공유용 웹페이지로 만듭니다. 30분 선행: 공통 환경 설정.
필수: 웹 조사·Sites 사용 가능 여부, 공식 자료 접속 시험. 내장 브라우저 경로 확인.
하네스 엔지니어링으로
파일 정리 에이전트 개선하기		 하네스 엔지니어링AI가 일할 자료·도구·권한·규칙 설계 (AGENTS.md) 원본 보존·실행 전 확인·저장 위치·검수 기준을 규칙으로 작성하고, 적용 전후 작업 과정과 결과를 비교합니다. 40분 선행: 기본 폴더 정리.
필수: 규칙 적용 전 결과와 AGENTS.md 예제. 규칙 읽기·적용 여부 시험.
파일 정리 에이전트의
스킬 제작과 재사용		 스킬 (Skill)반복해서 사용할 작업 순서와 판단 기준을 저장한 절차 파일 정리 과정과 검수 기준을 스킬로 만들고, 다른 예제 폴더에도 적용합니다. 30분 선행: 기본 폴더 정리 ➔ 하네스 적용.
필수: 스킬 저장·호출·재실행 확인. (공유 확장 시 P2 추가)
교과자료 분석 기반
수업 슬라이드 제작 에이전트		 콘텐츠 제작자료 분석부터 구성·제작·검수까지 수행 (PPTX) 교과자료 핵심과 수업 흐름을 정리하고, 교사 설명·발문·출처를 발표자 노트에 담은 수업 PPT를 만듭니다. 50분 선행: 공통 기초, 교과자료 분석·학습목표·아웃라인 준비.
필수: PPTX 생성·열람 환경, 글꼴·템플릿.
Canva 연동
카드뉴스 제작 에이전트		 Canva 연동외부 디자인 서비스 연결 및 카드뉴스 제작 수업 핵심 내용을 카드뉴스 원고로 바꾸고, 캔바 템플릿을 활용해 시각 자료로 제작합니다. 50분 선행: 공통 기초, 수업 원고/분석 결과.
필수: Canva 계정·연결·복사 가능한 템플릿. (Chrome 모듈 선행 권장)
Notion 연동
수업자료 정리 에이전트		 Notion 연동외부 자료 관리 공간 연결 및 수업 아카이빙 학습목표·핵심 개념·헷갈리기 쉬운 내용·참고 출처를 노션 수업 정리 페이지로 만듭니다. 50분 선행: 공통 기초, 수업 원고/분석 결과.
필수: Notion 계정·작업공간 연결, 페이지 생성·공유 권한 시험.
맞춤형 메일 응대
에이전트 제작		 업무 규칙 & Gmail말투/답변 기준 설정, Gmail 초안 저장과 절차 재사용 메일 15통의 요청·기한·회신 필요 여부를 분석하고, 답장규칙.md를 반영한 초안과 첨부문서를 만듭니다. 150분 선행: 공통 기초 (하네스 기초 권장).
필수: 샘플 메일·답장 규칙·문서 생성 환경. Gmail 계정·권한 확인.
자료 기반 토론 수업지원
에이전트 제작과 인용 검증		 자료 기반 & 인용 검증제공 발췌문 근거 답변, 원문 대조 검증 (Python) Python 실행 확인 후 논제·근거카드·활동지·루브릭을 만들고, AI 토론 모의실행 및 인용 확인 보고서를 만듭니다. 150분 선행: 공통 기초, P1 Python 준비(20분).
필수: 발췌문·검증기·시험 로그. 하네스 권장.
Git과 GitHub를 활용한
스킬 저장과 공유		 Git & GitHub작업 기록과 저장소 연결, 스킬 저장·공유 공간 Git 설치·GitHub 인증과 저장소 연결을 확인하고, 완성한 스킬 1개를 설명서·예제와 함께 올려 다시 받아 사용 가능한지 확인합니다. 50분 선행: 공유할 스킬 제작 완료.
P2 설치·연결 확인 30분 + 실제 공유 20분 (총 50분 포함).

※ 시간 기준: 1차시 = 수업 50분 + 휴식 10분. 토론 본 실습은 150분이며 P1 Python 준비 20분을 별도 배정합니다. 스킬 공유 50분에는 P2 준비 30분과 실제 공유 20분이 포함됩니다.

순수 수업 시간 기준
과정 도달 단계 수업 시간 구성 수업 합계 편성 범위 및 세부 안내
3차시 기초와 웹체험 기초 100 + 웹체험 50 150분 환경 설정·영수증·기본 폴더 정리 후 Chrome·웹 리서치·Sites 체험
4차시 하네스 적용 입문 기초 100 + 웹체험 50 + 하네스 40 + 확인 10 200분 로컬 스킬 단계의 앞부분까지 진행. 스킬 제작 30분은 6차시부터 편성
6차시 로컬 스킬과 PPT 제작 기초 100 + 웹체험 50 + 로컬 스킬 70 + PPT 50 + 검수 30 300분 폴더 정리 스킬 제작·재사용 후 수업 PPT 제작까지 완성
8차시 콘텐츠 제작까지 완성 기초 100 + 웹체험 50 + 로컬 스킬 70 + 콘텐츠 150 + 검수 30 400분 PPT·Canva·Notion 각 50분. 연결·공통 원고 준비는 해당 시간에 포함
12차시 메일과 토론 입문 기초 100 + 웹체험 50 + 로컬 스킬 70 + 콘텐츠 150 + 메일 150 + Python 20 + 토론 입문 60 600분 토론 입문은 발췌문 분석·논제·근거카드 중심 (기존 실습 완성을 위해 개인자료 적용 80분으로 변경 가능)
14차시 (참고) 토론 전체까지 완성 기초 100 + 웹체험 50 + 로컬 스킬 70 + 콘텐츠 150 + 메일 150 + Python 20 + 토론 전체 150 + 검수 10 700분 AI 토론·인용 검증·스킬화까지 완전 완성 (GitHub 공유는 다음 단계)
15차시 (전체) 스킬 공유까지 전체 기초 100 + 웹체험 50 + 로컬 스킬 70 + 콘텐츠 150 + 메일 150 + Python 20 + 토론 전체 150 + 공유 50 + 검수 10 750분 마지막 공유 50분 = Git·GitHub 준비 30분 + 실제 스킬 공유 20분. (총 900분, 휴식 150분 포함, 식사 별도)

실습 지연 방지

오프라인 선행 준비 과정 (P1 · P2)

  • P1 (Python 설치/실행 20분) 토론 인용 검증기 실행 전 필수, 앱 버전 확인 및 시험 로그 리포트 열기
  • P2 (Git/GitHub 연결 30분) 스킬 공유 모듈 전 필수, 사용자 정보 설정 및 시험 파일 커밋·푸시
  • 공유 (스킬 업로드 20분) P2 완료 후 스킬·설명서·예제만 선별 업로드 및 링크 점검
  • 연결 & 자료 준비 Chrome·Canva·Notion·Gmail 로그인/쓰기 시험(10~20분), 교과 공통원고 확정(20~30분)

개강 전 환경 완료 기준 점검

1. 공통 환경 앱에서 예제 파일을 읽고 지정 폴더에 새 결과물 저장
2. Python 환경 버전 확인 후 시험 로그로 인용 검증 보고서 생성
3. Git과 GitHub 계정 인증 후 시험 파일 푸시 및 다시 받기
4. 스킬 환경 목록 표시뿐 아니라 새 입력값으로 재실행 시험
5. 문서 제작 엑셀·PPT 생성 후 실제 열어 한글/표 확인
6. 보안 및 권한 개인정보 제외, 저장소 공개 범위 사전 검토
